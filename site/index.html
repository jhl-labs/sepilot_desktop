Sepilot Desktop은 내 컴퓨터에서 도는 데몬 sepilotd와 함께 동작합니다. 채팅, 코드 분석, 개인 비서, 캘린더와 칸반 같은 내장 앱, 도구와 확장 관리를 한 창에서 다룹니다.

다운로드 GitHub

스프린트 계획을 부탁한 대화. 표와 목록이 바로 정리되고, 아래 입력창에서 모델·권한·작업 폴더를 고릅니다.

하나의 데몬

터미널에서 시작한 대화를 앱에서 이어 갑니다

CLI와 데스크톱은 같은 컴퓨터의 sepilotd 하나를 함께 씁니다. 세션, 승인 기록, 메모리, 예약 작업이 한곳에 쌓이므로 어느 화면에서 시작했든 다른 화면에서 그대로 이어집니다.

  • 창을 닫아도 트레이와 데몬은 계속 실행되어 예약 작업이 멈추지 않습니다.
  • Ctrl/⌘+Alt+Space 빠른 입력창으로 다른 앱을 쓰다가도 바로 묻습니다.
  • 로그인할 때 자동 시작, 새 대화, 데몬 종료를 트레이 메뉴에서 다룹니다.
~/projects/web-shop $ sepilot ask --mode instant \ "다음 주 web-shop 스프린트 계획 초안을 만들어줘" … 목표 · 작업 표 · 위험 요소를 정리했습니다. ~/projects/web-shop $ sepilot sessions list 71c911f3 web-shop 다음 주 스프린트 계획 초안 completed

CLI에서 만든 이 세션이 위 데스크톱 화면의 대화 목록에 그대로 나타납니다.

대화와 코드

작업 폴더를 열어 두고 물어보세요

대화마다 작업 폴더를 연결하면 에이전트가 파일을 읽고 명령을 실행해 근거를 모읍니다. 실행한 도구는 작업 로그로 접혀 남고, 답변에는 원인과 위치가 정리됩니다.

  • 작업 로그 — 어떤 도구가 몇 번 성공·실패했는지 펼쳐 봅니다.
  • 파일 변경 검토와 되돌리기 — 에이전트가 바꾼 파일을 확인하고 되돌립니다.
  • 감독 모드 — 편집과 명령은 승인한 것만 실행됩니다.
  • 메시지 분기·재생성·낭독 — 특정 지점에서 갈라 다시 묻고, 답변을 소리로 듣습니다.
실행 방식

요청에 맞는 실행 방식을 고릅니다

기본값인 알아서 선택은 요청 성격을 보고 실행 방식을 정합니다. 직접 고를 수도 있습니다.

  • 즉시 응답은 도구 없이 빠르게, 일반 작업은 도구를 쓰며 처리합니다.
  • 사고·연구는 단계적 추론과 심층 웹 조사, 개발은 코딩 루프와 심화 코딩입니다.
  • 협업은 여러 페르소나가 함께 검토하고, Codex·Claude Code·OpenCode CLI를 대화 엔진으로 쓸 수도 있습니다.
  • 역할 봇(개발자, 아키텍트, 코드 리뷰어, 비서 등)을 골라 전문 영역을 지정합니다.
나의 비서

오늘 할 일을 함께 정리합니다

비서 홈에서 오늘 계획 세우기, 회의 준비, 반복 브리핑 만들기, 하루 마무리 같은 일을 바로 시작합니다. 일정과 할 일, 기억해 둔 선호가 함께 반영됩니다.

  • 반복 브리핑은 Tasks에 예약되어 데몬이 시간에 맞춰 실행합니다.
  • Google 계정과 메일 같은 서비스를 연결해 일정 신호를 넓힙니다.
  • 기억한 선호와 결정은 다음 대화에서도 참고됩니다.
내장 앱

에이전트와 데이터를 나누는 작은 앱들

캘린더, 할 일, 오늘의 브리핑, 칸반, 스티키, 보안 금고가 기본으로 들어 있습니다. 각 앱은 샌드박스 안에서 실행되고, 에이전트는 허용된 앱 데이터만 읽고 고칩니다.

월간 달력과 일정 목록을 함께 봅니다. 회의 일정은 할 일·칸반과 연결됩니다.

보안 금고는 암호 구문으로 업무 메모를 암호화해 보관합니다.

도구와 확장

에이전트가 쓸 도구를 직접 정합니다

도구 카탈로그에서 그룹별로 켜고 끄며, 기본 대화가 차지하는 컨텍스트 크기를 바로 확인합니다. MCP 서버와 스킬도 같은 화면에서 관리합니다.

  • 파일, 터미널, git, 웹 검색, 브라우저 제어, 메모리, 문서 작성 도구
  • MCP 서버 연결과 도구별 허용
  • 설치형 스킬과 사용자 Agent 정의
  • 웹 검색 출처 경계, 이미지 생성, 음성 설정

3분 안에 끝나는 첫 설정

처음 실행하면 모델 제공자와 기본 작업 폴더만 고르면 됩니다. 나머지는 기본값으로 시작하고 언제든 설정에서 바꿉니다.

다크 모드로 바꾸고, 작업 상태를 알려 주는 데스크톱 펫을 다른 창 위에 띄울 수 있습니다.

그 밖의 기능

매일 쓰는 데 필요한 것들

파일 첨부와 음성

파일과 이미지를 붙이고, 음성으로 입력하거나 답변을 낭독합니다.

지식과 문서

위키, 개인 문서, 팀 문서, RAG 소스를 모아 대화에서 찾습니다.

메모리

SQLite 전문 검색과 벡터 검색, 장기 기억과 활동 기록을 관리합니다.

예약 작업

반복 브리핑과 정해진 시각의 작업을 Tasks에서 만들고 멈춥니다.

알림과 메신저

Slack, Telegram, Discord 등 채널과 발신 웹훅으로 결과를 보냅니다.

브라우저 탭 공유

Chrome 확장으로 고른 탭 하나만 에이전트에게 맡기고 언제든 되찾습니다.

작업 폴더 격리

대화마다 작업 폴더를 정하고, 그 밖의 경로는 실행 범위에서 막습니다.

컨텍스트와 백그라운드

컨텍스트 사용량을 보며 긴 작업은 백그라운드로 돌립니다.

한국어·영어

화면 언어와 테마를 설정에서 바꿉니다.
