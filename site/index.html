로컬 우선 AI 에이전트

에이전트에게 얼마나 맡길지, 키 하나로 정합니다.

Sepilot은 내 컴퓨터에서 실행되는 데몬 sepilotd 위에 터미널 CLI와 데스크톱 앱을 올린 AI 에이전트입니다. 세션, 도구, 승인, 메모리는 데몬 하나가 관리하고, 두 화면은 같은 작업을 이어서 다룹니다.

설치하기 최신 릴리스
sepilot — ~/projects/web-shop

› 설치 안내가 틀렸어. README 고치고 테스트 돌려줘

계획: 파일 확인 → 문서 수정 → 테스트 실행

1fs.read README.md
2fs.edit README.md
3terminal.run pnpm test
Shift+Tab

모드 버튼을 누르거나 버튼에 포커스한 채 Shift+Tab을 누르면, 실제 TUI처럼 권한 모드가 바뀝니다. 같은 요청이라도 모드에 따라 자동으로 실행할 일과 승인을 받을 일이 달라집니다.

구조

한 데몬, 두 개의 화면

CLI와 데스크톱은 얇은 화면입니다. 실제 에이전트 실행과 도구 호출, 승인 정책, 기록은 모두 로컬 데몬이 맡습니다. 같은 컴퓨터의 CLI와 데스크톱은 데몬 하나를 함께 씁니다.

sepilot CLI

터미널에서 대화하고, 스크립트에서 부릅니다

인자 없이 실행하면 대화형 TUI가 열리고, 명령으로 쓰면 파이프와 CI에 그대로 연결됩니다. 데몬이 내장된 단일 실행 파일이라 따로 설치할 런타임이 없습니다.

스크롤을 지키는 인라인 TUI

화면 전체를 차지하지 않고 터미널 기록 위에 이어서 그립니다. @파일로 파일을 첨부하고, 클립보드 이미지를 붙여 넣고, !로 시작하면 로컬 셸 명령을 바로 실행합니다.

# 대화 시작
sepilot

슬래시 명령으로 전환

모델, 역할 봇, 실행 모드를 대화 중에 바꿉니다. 승인 대기, 변경 diff, 작업 목록, 사용량도 패널로 엽니다.

/model/bot/mode/diff/approvals/rewind

되감고, 가지치고, 내보내는 세션

지난 세션을 이어 가거나 특정 지점에서 갈라 새로 시도합니다. 대화와 파일 변경을 함께 되돌리고, 결과를 문서로 내보냅니다.

sepilot sessions branch <id>
sepilot rewind <id>

자동화에 맞춘 출력

한 번 묻고 끝내거나, 이벤트를 줄 단위 JSON으로 받아 다른 도구로 넘깁니다. JSONL 파일로 여러 작업을 한꺼번에 돌립니다.

git diff | sepilot ask "이 변경을 리뷰해 줘"
sepilot -p "..." --output-format stream-json

예약과 백그라운드 작업

cron이나 자연어로 반복 작업을 걸고, 결과를 메신저로 받습니다. 오래 걸리는 일은 백그라운드 작업과 서브에이전트로 나눕니다.

sepilot schedule add
sepilot jobs

다른 코딩 에이전트와 함께

Claude Code, Codex, Gemini CLI, OpenCode를 swarm으로 띄워 일을 나누고, 실행 중인 세션에 붙어 지켜봅니다. ACP 서버로 편집기와도 연결합니다.

sepilot swarm run
sepilot swarm attach <id>
Sepilot Desktop

항상 곁에 있는 데스크톱 작업 공간

창을 닫아도 트레이에 남아 있다가 단축키 하나로 질문을 받습니다. 대화 외에도 지식 관리와 일상 업무용 앱을 함께 담았습니다.

모드와 엔진을 고르는 채팅

빠른 답변부터 코딩, 심층 웹 조사, 페르소나 토론까지 작업에 맞는 모드를 고릅니다. Codex, Claude Code, OpenCode CLI를 대화 엔진으로 쓸 수도 있습니다.

autocodingdeep-web-researchpersona-panel

어디서든 빠른 입력

다른 앱을 쓰다가 Ctrl/⌘ + Alt + Space로 입력창을 띄워 바로 묻습니다. 자주 쓰는 질문은 단축키로 등록합니다.

트레이에서 관리

연결 상태를 확인하고, 새 대화를 열고, 로그인할 때 자동으로 시작하도록 설정합니다. 창을 닫아도 데몬과 예약 작업은 계속 돌아갑니다.

쌓이는 지식

대화에서 기억할 것을 메모리로 남기고, 위키와 개인 문서, RAG 소스를 한곳에서 찾습니다. 검색은 로컬 SQLite 전문 검색과 벡터 검색을 함께 씁니다.

내장 앱

에이전트가 함께 다루는 작은 앱을 기본으로 제공합니다. 볼트는 암호구로 잠급니다.

캘린더할 일데일리 브리핑스티키 노트볼트칸반

브라우저 탭 공유

Chrome 확장으로 고른 탭 하나만 에이전트에게 맡기고, 언제든 제어를 되찾습니다. 확장은 앱 안에서 설치합니다.

sepilotd

두 도구가 함께 쓰는 엔진

CLI와 데스크톱의 기능은 대부분 데몬에서 옵니다. 어느 화면에서 시작한 작업이든 같은 정책과 기록 아래에서 실행됩니다.

모델
Ollama, OpenAI, Anthropic, Gemini, Groq, Together, DeepSeek, OpenRouter와 OpenAI 호환 엔드포인트. 장애가 나면 다른 제공자로 넘깁니다.
에이전트 엔진
빠른 답변(instant), 도구 루프(react), 경량 coder와 다단계 deep-coder, 리서치 그래프, 역할 봇.
도구
파일 읽기·편집·패치, 터미널과 백그라운드 프로세스, 웹 검색·가져오기, CDP 브라우저 제어, git, LSP 기반 코드 탐색.
승인과 보안
권한 모드와 정책 엔진, 기억되는 결정, 암호화된 비밀 저장소, 감사 로그, Docker·bubblewrap 샌드박스.
메모리
SQLite FTS5와 벡터 검색, MEMORY.md와 일일 노트, 리마인더, git·웹 동기화 RAG.
스킬과 MCP
문서(pptx·docx·xlsx) 작성 스킬과 마켓플레이스. MCP 서버는 stdio, SSE, streamable HTTP로 연결합니다.
메신저
Telegram, Slack, Discord, Mattermost, Teams, LINE, WhatsApp, 웹챗, 웹훅, GitHub Issues.
연동
OpenAPI 문서가 붙은 HTTP·WebSocket API, A2A 에이전트 카드, ACP 서버, 수신·발신 웹훅과 이벤트 라우팅.
설치

필요한 화면부터 설치하세요

모든 바이너리는 GitHub Actions가 공개 저장소에서 빌드해 GitHub Releases에 올립니다. 설치 후 ~/.sepilotd/config.yaml이나 앱 설정에서 모델 제공자를 연결합니다.

sepilot CLI

Linux(x64, arm64), macOS(x64, arm64), Windows(x64). 설치 스크립트가 플랫폼에 맞는 릴리스를 받아 SHA-256 체크섬을 확인합니다.

curl -fsSL https://raw.githubusercontent.com/jhl-labs/sepilot-cli/main/packages/bundle/scripts/install.sh | sh
irm https://raw.githubusercontent.com/jhl-labs/sepilot-cli/main/packages/bundle/scripts/install.ps1 | iex
업데이트는 sepilot upgrade, 상태 확인은 sepilot status로 합니다.

Sepilot Desktop

데몬을 앱 안에 담고 있어 따로 설치할 것이 없습니다. 최신 릴리스에서 내 운영체제용 파일을 받으세요.

  • Windowsportable .exe
  • macOS (Apple Silicon)arm64-mac.zip
  • macOS (Intel)mac.zip
  • LinuxAppImage
macOS 빌드는 서명되지 않았습니다. 처음 실행할 때 Finder에서 앱을 우클릭한 뒤 열기를 선택하세요.
